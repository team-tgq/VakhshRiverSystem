# 瓦赫什流域孪生数据样例

本目录为集成整改样例数据，只用于演示目录结构、字段命名、单位和模块链路。
样例数据均为小尺寸模拟数据，不代表真实瓦赫什流域观测值。
当前 `200503_融雪期`、`201707_汛期` 只是示例时段，用来展示“年份月份_业务时段”的命名方式，不表示项目必须使用这两个年月。

- baseline/: 固定基准数据，统一 EPSG:32642，矢量和 DEM 均裁剪在样例流域边界内。
- raw/: 原始观测数据，按 时段_名称 组织；GeoTIFF 均带坐标信息，CSV 均包含 `date` 字段。
- processed/: 模型成果，按 方案_工况/时段_模拟类型/raster|table 组织。
- *.meta.json: 每个样例成果的旁路元数据，记录 CRS、时间字段、模块编号、字段、单位和来源。
- finish.tag: 方案时段完成标记，可供 Qt 或三维展示监听。
- demo_only=true: 表示该文件仅用于目录、字段和链路演示，不得作为正式瓦赫什流域计算结果。
